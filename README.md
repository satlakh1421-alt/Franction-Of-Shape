# 🔷 Fraction Of Shape
An engaging, visual educational game designed to help learners understand, visualize, and master geometric fractions and parts of a whole through interactive shapes!

## 🚀 Features
- **Visual Fraction Learning:** Identify, shade, and partition 2D shapes (circles, squares, rectangles, hexagons) to match target fractions.
- **Interactive Gameplay:** Hands-on interaction with shape segments to make abstract fraction concepts concrete.
- **Progressive Challenges:** Exercises scale from simple halves and quarters to more complex irregular fractions and mixed numbers.
- **Instant Visual Feedback:** Real-time checking to reinforce understanding and correct mistakes immediately.
- **Clean & Lightweight:** Optimized for smooth, responsive performance in any modern browser.

## 🎮 How to Play
1. Start a new game session.
2. Read the fraction prompt (e.g., "Select 3/4 of the circle" or "What fraction is shaded?").
3. Click or tap the shape segments to shade/unshade them, or choose the correct multiple-choice fraction.
4. Submit your answer to score points and advance to the next challenge!
